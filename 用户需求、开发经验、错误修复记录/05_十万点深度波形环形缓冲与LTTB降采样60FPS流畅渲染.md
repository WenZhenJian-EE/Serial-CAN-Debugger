# 05_十万点深度波形环形缓冲与LTTB降采样60FPS流畅渲染

---

## 一、 为什么 2,000 点示波缓冲无法满足电力电子研发？

在旧版实现中，每个示波通道仅维护最新 **2,000 个采样点**：
- 当采样频率为 10kHz 时，2,000 点只能记录仅仅 **0.2 秒** 的波形；
- 在排查开关管开通震荡、死区时间畸变、电机启停阶跃瞬态响应或掉电保护过程时，波形瞬间被冲刷覆盖，工程师一旦点击“暂停”，关键故障瞬态早已滑出内存，根本无法完成精细化波形回溯。

为此，新版上位机提出硬核升级需求：**将内存环形缓冲区深度从 2,000 点扩大至 100,000 点（50 倍扩容）！**

---

## 二、 海量点阵渲染的致命挑战与 LTTB 降采样

然而，将缓冲区扩大至 100,000 点会引发严重的 Canvas 渲染性能危机：
- 如果每个通道 100,000 点全量提交给 Canvas 或 WebGL 进行连线绘制，8 个通道就是 **800,000 个几何顶点**；
- 屏幕物理分辨率通常只有 1920x1080 或 2560x1440，横向物理像素仅有约 1500px。在 1500 像素内塞入 100,000 个点，像素点彼此重叠，不仅对肉眼毫无可读性，而且会导致 GPU 光栅化开销暴增，帧率暴跌至 5~10 FPS，出现严重假死。

### 视觉保真核心：LTTB (Largest Triangle Three Buckets) 算法
为了兼顾“海量历史存储”与“60FPS 极速渲染”，本项目在 ECharts 系列配置中深度启用了 **LTTB 视觉无损降采样机制**：
1. **最大三角形三桶算法原理**：
   - 将 100,000 点数据划分为与屏幕像素宽度等同的若干个连续“桶（Bucket）”；
   - 在相邻三桶之间，动态计算由前一点、后一桶平均点与当前桶内候选点构成的三角形面积；
   - 选取**使三角形面积最大化**的候选点作为该桶的唯一定代表点；
2. **算法工程收益**：
   - **极致保真峰值与尖峰**：与均值降采样（会将开关毛刺抹平）或简单抽样（会漏掉窄脉冲）不同，LTTB 保证了瞬态电压过冲、尖峰毛刺和死区下冲百分之百被完整保留；
   - **渲染负载骤降 98%**：Canvas 绘制的点数从 100,000 稳定收敛为 1,500 左右，完全匹配显示器物理分辨率。

## 三、 60FPS 节流闭环架构：解耦数据推流与屏幕刷新

数据推送是高频异步的（可能以 5,000Hz 甚至更高的频率连续到达），而屏幕物理刷新率恒定为 60Hz（约 16.6ms 刷新一帧）。

绝对不能在接收到每个数据点时都调用 `chart.setOption()`！必须实现**数据解耦双循环**：

```text
[WebSocket 数据接收流 (5kHz+)]
             │
             ▼ push()
┌──────────────────────────────────────────────┐
│  JavaScript 内存环形缓冲 (MAX_POINTS = 100k) │
└──────────────────────────────────────────────┘
             │
             ▼ requestAnimationFrame (~16.6ms)
┌──────────────────────────────────────────────┐
│  ECharts 节流渲染主循环 (稳定的 60 FPS)       │
└──────────────────────────────────────────────┘
```

### 关键代码实现：
```javascript
// 60FPS 节流渲染主循环
function renderLoop() {
  const now = performance.now();
  frameCount++;

  // 1秒更新一次统计指标 (RMS, Pk-Pk, 渲染帧率 FPS)
  if (now - lastFpsUpdate >= 1000) {
    currentFps.value = frameCount;
    frameCount = 0;
    lastFpsUpdate = now;
    calculateChannelMetrics();
  }

  // 只有在未暂停且图表就绪时才执行 setOption
  if (myChart && !isPaused.value) {
    const seriesUpdate = channels.map((ch, idx) => ({
      id: `ch-${ch.id}`,
      data: ch.enabled ? seriesData[ch.id] : [],
      markLine: idx === 0 ? getMarkLineOption() : undefined,
    }));
    // ECharts 轻量增量同步
    myChart.setOption({ series: seriesUpdate });
  }

  animationFrameId = requestAnimationFrame(renderLoop);
}
```

## 四、 稳态物理量动态解算 (RMS & Pk-Pk)

不仅能够流畅看波形，系统还基于最新 200 个采样窗口，在后台微循环中实时解算电工学关键物理量：
- **真有效值 (True RMS)**：
  $$V_{\text{RMS}} = \sqrt{\frac{1}{N}\sum_{i=1}^N v_i^2}$$
- **峰峰值 (Peak-to-Peak)**：
  $$V_{\text{Pk-Pk}} = \max(v) - \min(v)$$
并在每个通道控制卡条上以毫秒级平滑刷新，为电源拓扑稳态分析提供最准确的实时量化依据。
