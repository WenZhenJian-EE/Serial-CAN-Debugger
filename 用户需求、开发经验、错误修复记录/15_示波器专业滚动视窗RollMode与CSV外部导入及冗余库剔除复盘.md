# 15_示波器专业滚动视窗RollMode与CSV外部导入及冗余库剔除复盘

## 📌 一、 需求背景与痛点诊断

在持续验证上位机示波器功能的过程中，针对工业示波与硬件调试场景，发现了四个关键问题与用户明确诉求：

### 1. 历史波形横向挤压成色块（最核心用户痛点）
- **现象复现**：开启仿真或高频接收信号后，随着运行时间推移（5秒、10秒、30秒……），X 轴时间轴持续无限向右扩张（从 0s 累积至数十秒）。波形在固定宽度的屏幕画布内被极度压缩，原本清晰的正弦波、PWM 方波、三角波全都被挤成了一团黑乎乎、密不透风的纯色条带（正如用户截图所示）。
- **物理本质根因**：原绘图逻辑将 X 轴范围默认设为包含所有历史点的绝对时间 `[0, latestT]`。随着采样点数和时间增长，固定像素宽度（如 1200px）内需要塞入成百上千个完整周期，单位像素覆盖了多个周期的高低电平，在屏幕上必然发生严重的视觉混叠（Aliasing），彻底失去波形可读性，并且长时间运行还会无谓消耗 CPU。
- **工业示波器标准规范**：专业数字存储示波器（DSO）在连续运行模式下，必须采用**滚动视窗模式（Roll Mode / Sliding Time Window）**——固定横向观察的时间跨度（如 2.0s、1.0s、0.5s、5.0s 等），波形从右侧平滑进入、向左滚动推移。仅显示当前窗口内的动态周期细节，确保无论运行 1 分钟还是 10 小时，波形细节永远清晰如初！

### 2. 仿真波形按钮点击响应迟滞
- **现象复现**：点击顶部导航栏中的“仿真波形”按钮时，由于定时器初始状态未立即重置暂停锁，或者必须等待下一个 100ms 周期才灌入首帧数据，导致给用户的体感是“点了没反应”。
- **优化要求**：点击按钮时，瞬间取消暂停状态（`isPaused = false`），并在毫秒级同步注入首批 100 个仿真点完成首帧即时渲染，按钮视觉状态同步切换为绿色脉冲运行态，提供立竿见影的零延迟交互反馈。

### 3. 外部数据导入功能丢失（CSV 数据文件导入）
- **用户诉求**：示波器必须具备回放与离线分析外部采集设备记录的 `.csv`/`.txt` 数据文件的能力。
- **功能定位**：用户可一键点击“导入 CSV”，选择本地数据文件，系统支持宽表格式（`Time,CH1,CH2,CH3...`）、长表格式（`Time,Channel_ID,Value`）或双列时序数据，自动解析通道、自适应缩放坐标轴、冻结当前波形、并联动 Cursor A/B 光标进行精确物理测量。

### 4. 界面中残留的无关功能（元器件与磁芯规格数据库）
- **用户反馈**：“看图片 2，这个功能是啥玩意啊？我是做的示波器啊，这个功能给我删除掉，我都不知道是啥玩意啊”。
- **清理范围**：上位机定位于高频工控示波与串口/CAN调试器，原本遗留的“元器件与磁芯规格数据库”弹窗、图标、路由及数据库表完全与产品定位脱节，必须 100% 彻底拔除，净化整个系统的代码与界面架构。

## 🛠️ 二、 核心架构重构与算法突破

### 1. 示波器 Roll Mode 动态滑动视窗与二分抽取架构

为了彻底解决波形压缩问题，我们在 `WaveformChart.vue` 中重构了时间轴与数据抽取引擎：

```
+-------------------------------------------------------------------------+
|                  100,000 点深度环形缓冲区 (All Historical Points)          |
|  [Point 0, Point 1, ..., Point K] -> -> -> [Point N-Window, ..., Point N]|
+-------------------------------------------------------------------------+
                                                     |
                                   O(log N) 快速二分搜索确定可视窗口
                                                     v
                                  +---------------------------------------+
                                  | 可视时间窗: [t_latest - Tw, t_latest]  |
                                  | (默认 Tw = 2.0s，可选 0.5s ~ 10s)      |
                                  +---------------------------------------+
                                                     |
                                    Min-Max 极值峰值保真降采样 (<0.1ms)
                                                     v
                                  +---------------------------------------+
                                  | 屏幕画布 GPU 渲染序列 (~2,000 点)      |
                                  | 晶莹剔透、无压缩、固定周期细节完美呈现  |
                                  +---------------------------------------+
```

#### (1) 二分搜索精准切片 (`getWindowedDownsampledData`)
为了避免对整个 10 万点历史数据进行全量遍历（这将导致高昂的 CPU 开销），我们利用时间戳严格单调递增的物理特性，在进入 Min-Max 降采样之前，通过两次二分查找（`binarySearchLeft` / `binarySearchRight`）在 $O(\log N)$ 耗时内（通常只需 16 次比对，耗时 $< 0.01\text{ms}$）精确定位可视窗口内的点索引范围 `[iStart, iEnd]`。

#### (2) 滑动时间窗实时计算
在连续推流渲染中，X 轴的显示范围固定为：
$$\text{xAxis.min} = \max(0, t_{\text{latest}} - T_w)$$
$$\text{xAxis.max} = \max(T_w, t_{\text{latest}})$$
其中 $T_w$ 为用户选择的时间跨度（支持 `0.5s`、`1.0s`、`2.0s`、`5.0s`、`10.0s` 或 `全量(All)`）。波形从画布右侧进入，向左平滑推移，屏幕上始终保持固定周期的清晰波形！

#### (3) 运行与暂停模式状态机解耦
- **运行状态（Running）**：启用固定滑动时间窗 $T_w$，隐藏底部数据缩放条，波形平滑连续滚动。
- **暂停状态（Paused / Freeze）**：波形瞬间冻结，系统立即自动激活并弹出底部 `dataZoom` 交互滑块，用户可以通过滚轮缩放、拖拽时间轴滑块，在整个 100,000 点的历史长河中任意回放和定位任一历史时间段，配合 Cursor A/B 光标完成精密测绘。

### 2. 外部 CSV 数据文件高兼容解析引擎

在 `WaveformChart.vue` 中设计了专业的客户端无依赖 CSV 解析引擎 `parseAndLoadCsv`：

1. **宽表格式兼容**：第一行为时间戳，后续列为各通道数值（如 `Time,CH1,CH2,CH3,CH4`），自动提取各通道时序序列；
2. **长表格式兼容**：支持 `Time,Channel_ID,Value` 三列经典工控导出格式，按通道 ID 自动分组聚合；
3. **两列简易格式**：支持 `Time,Value` 单通道波形。
4. **导入后自动装载**：
   - 自动清空并注入到对应通道的环形缓冲区中；
   - 自动推算最小和最大时间范围；
   - 自动切换为“全量 (All)”视窗并触发**暂停冻结模式**；
   - 自适应撑开 Y 轴量程，Cursor A/B 光标自动贴靠在有效数据段，便于用户直接测量分析。

## 💡 四、 总结与最佳实践

1. **工控示波器的本质是“滚动观察”，而非“无限累积”**：
   长时间连续采集时，屏幕画布物理像素是有限的。无限延长时间轴必然导致高频波形被压缩为色块，引发严重的混叠伪影。通过引入硬件示波器标准的 **Roll Mode**，并提供 0.5s、1.0s、2.0s、5.0s、10.0s 多档可选视窗，完美平衡了“动态观测波形细节”与“全局趋势把控”。
2. **动静分治：运行看窗口，暂停看全量**：
   在实时推流时锁定滑动时间窗保持最佳流畅度；在点击暂停时瞬时释放全量 10 万点历史并激活 `dataZoom` 滑块，既保证了实时推流下的高帧率，又满足了事后深挖异常波形和光标微观分析的需求。
3. **极简工程交付**：
   坚决剔除无关业务逻辑与冗余功能，保持 Serial-CAN-Debugger 作为工业级高性能通用串口/CAN示波器的专业度与纯粹性。
