# 第23章：布局人机工程重构·硬件触发常驻侧边栏与系统环境自适应识别

## 1. 业务演进与用户核心诉求

随着软件逐步推向国际开源社区与实际硬件产线，用户针对人机交互效率与全球化开箱体验提出了两项关键要求：

1. **左侧控制面板重构：硬件触发下沉至侧边栏中央**：
   > “这个功能也放到这里，这些是通用的。自定义调试放到下面，硬件触发放到中间”
   - **痛点分析**：先前将【硬件触发】放在顶部导航栏的第二个主选项卡（实时示波、硬件触发、报文监视、Bode扫频），导致工程师在配置边沿触发极性、通道与电平阈值时，无法实时观察右侧的示波动态响应，必须在两个标签页之间来回切换；
   - **人机工程重构**：【硬件触发】与【自定义控制】本质上都是全局通用的硬件调试手段，应当与【串口总线】/【CAN总线】一同常驻在左侧 350px 侧边栏：
     - **上部**：当前硬件总线通信参数与状态（`SerialPanel` / `CanPanel`）；
     - **中部**：示波器硬件级边沿触发器（`OscTriggerPanel`，模式/通道/极性/阈值微调/ARM）；
     - **下部**：自定义控制矩阵（`CustomButtonsPanel`，自由命名的指令按键与调参滑块）。
   - **顶部主视图回归纯净**：顶部导航栏聚焦于三大显示与分析主视图：
     - `1. 实时示波 (Waveform)`
     - `2. 报文监视 (Monitor)`
     - `3. Bode 扫频 (Bode Plot)`
     - 快捷键自适应对齐为 `1` ~ `3` 数字键秒切。

2. **操作系统运行环境语言自适应识别（智能免切）**：
   > “并且能否自动识别使用人的本地电脑环境呢？就是他们如果是英文系统的话，打开这个软件直接就是英文，不需要手动切换。因为这个软件我开源出去之后，大部分使用者应该都是国外的外国人”
   - **开箱即用体验**：面向海外开源社区分发时，若非中文用户打开软件呈现全中文，会极大增加认知门槛；
   - **无感环境适配**：在 `i18n.js` 中构建自适应识别算法：
     - 优先读取 `localStorage` 中用户曾经主动选定的语言偏好；
     - 若首次启动，通过 `navigator.languages` 与 `navigator.language` 探测操作系统环境：
       - 非中文系统（英文、德文、日文、法文等国际环境）：自动默认呈现纯正英文（`en-US`）；
       - 中文系统（`zh-CN` / `zh-TW` / `zh-HK`）：自动呈现简体中文；
     - 顶部保留 `中 / EN` 极速切换按钮，保证任何时候用户均可一键手动覆写。

## 2. 侧边栏三权协同布局架构

在 `webui/src/App.vue` 中重组侧边栏内容流：
```html
<div class="sidebar-content">
  <!-- 1. 硬件总线配置卡片 (串口 UART 或 CAN/CAN-FD) -->
  <SerialPanel v-show="sidebarTab === 'serial'" ... />
  <CanPanel v-show="sidebarTab === 'can'" ... />

  <!-- 2. 硬件边沿触发器 (常驻中央，边调阈值边看波形) -->
  <OscTriggerPanel @toast="showToast" />

  <!-- 3. 自定义调试控制矩阵 (常驻底部，按钮与无级滑块) -->
  <CustomButtonsPanel :activeBus="sidebarTab" ... />
</div>
```

同时对 `OscTriggerPanel.vue` 进行侧边栏适配改造：
- 剔除先前页面居中的 `max-width: 600px; margin: 0 auto;` 冗余样式；
- 增加 `margin-top: 10px; flex-shrink: 0;`，完美契合 350px 侧边栏宽度并支持纵向滚动；
- 黑匣子越限录波参数行启用 `flex-wrap: wrap;`，窄屏自适应规整排列。

## 3. 运行环境语言自适应识别算法

在 `webui/src/i18n.js` 中重写初始化状态机：
```javascript
function detectInitialLocale() {
  try {
    const saved = localStorage.getItem(STORAGE_KEY);
    if (saved && (saved === 'zh-CN' || saved === 'en-US')) {
      return saved;
    }
  } catch (_) {}

  try {
    const sysLang = (typeof navigator !== 'undefined' && navigator.languages && navigator.languages.length > 0)
      ? navigator.languages[0]
      : (typeof navigator !== 'undefined' ? (navigator.language || navigator.userLanguage || '') : '');
    if (sysLang && sysLang.toLowerCase().startsWith('zh')) {
      return 'zh-CN';
    }
    return 'en-US';
  } catch (_) {
    return 'en-US';
  }
}

export const currentLocale = ref(detectInitialLocale());
```
- 海外用户双击 `.exe` 直接启动英文界面，无需任何配置；
- 国内用户双击 `.exe` 默认中文界面，无缝贴合母语使用习惯。
